# 商店素材

| 文件 | 用途 | 规格 |
|---|---|---|
| `ic_store_512.png` | 应用市场列表图标（Google Play「应用图标」、各家国内市场同名字段） | 512×512，32 位 PNG，无透明通道 |

**这个目录不参与打包**，不在 `app/src/**` 里，Gradle 不会看它一眼。
商店图标是上传到控制台的素材，把它塞进 `res/` 只会让每个用户的手机里
多躺一张自己永远看不到的 512×512 位图。

素材是按 `res/drawable/ic_launcher_foreground.xml` 的几何等比放大渲染的，
**注意它没有圆角**：Google Play 会自己套蒙版，国内几家市场大多也一样。
如果某个市场要求自带圆角，用 22% 的圆角半径（512 → 113px）自己裁一版，别改这张。

改了启动图标，这张要跟着重出，否则商店里和手机上的图标会是两个东西。
